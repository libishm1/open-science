## Other errors noticed in passing

1. **Peng et al. quotation (dossier 2.2).** "significantly degrades" is not in the paper. The paper says "bringing significant translation degradation". See claim 8.
2. **Tiny Aya Arabic table (dossier 1.2a) is incomplete.**
   - Tiny Aya Water ties Earth for the best Flores en-ar score (0.53), so the bold on Earth alone overstates it.
   - Tiny Aya Fire is the best Tiny Aya variant on WMT24++ Arabic: ar_EG 0.31 and ar_SA 0.36, against Earth's 0.30 and 0.34. This weakens "Earth tuned for West Asia" as a reason to prefer Earth for Arabic.
   - SmolLM3-3B scores 0.44 / 0.24 / 0.28 on en-ar. That is above Qwen3-4B on Flores (0.42) and above Ministral-3-3B on all three. Excluding SmolLM3 for Arabic is therefore justified by its overall average and missing language support, not by its Arabic chrF.
3. **Tamil addendum 6.2.2, "All models scored below this copy baseline for every language except Hindi".** This holds only for Vajjala's own Gemma 3 runs, not for the shared task:
   - Malayalam submissions beat the copy baseline (96.02 and 95.06 against 94.42).
   - The Bangla and Telugu winners equal it (95.79 = 95.79; 88.17 = 88.17).
   - Tamil is the only language where the copy baseline beats the winner (92.17 > 91.57).
4. **llama.cpp default temperature.** The "T 0.8" server default applies to the native and OpenAI-compatible endpoints. The messages-style `/v1/messages` endpoint documents a default temperature of 1.0 in the same README. The advice to send sampling parameters explicitly covers this.
5. **Sources to cite.**
   - Dossier source #106 cites Art. 50 through artificialintelligenceact.eu. Cite the EUR-Lex ELI instead (http://data.europa.eu/eli/reg/2024/1689/oj).
   - Source #107 can now cite the Official Journal (Regulation (EU) 2026/1744) instead of law-firm summaries.
6. **Values spot-checked beyond the brief.** These match the source exactly:
   - TranslateGemma Table 4 en->ta_IN MetricX: TG 2.87 / 2.98 / 3.90; Gemma 3 3.53 / 3.83 / 5.04.
   - Vajjala's GLEU range for near-identical outputs: 85.33 to 100.
   - The Qwen3-4B-Instruct-2507 WritingBench and MultiIF figures.

Help

Windows says it protected my PC

The installer is not code-signed, so SmartScreen warns about it. Choose More info, check that the file came from the releases page, then Run anyway.

A model fails with "read GGUF metadata ... size overflows"

The model file was downloaded for an older Ollama. Run ollama rm <model> and then ollama pull <model>.

Replies are very slow

The model is larger than your GPU memory and runs on the CPU. Use the smaller option on the Local models page, or close other programs that use the GPU.

The app cannot reach Ollama

Start the Ollama app (or run ollama serve). In the app, the provider address is http://localhost:11434, with no key.

Is my data sent anywhere?

Not with local models. Cloud models are used only if you add a key and choose a cloud model. With the command-line workbench, python -m lawb cloud-log lists every cloud call.

The command line prints strange characters

Update to the latest workbench. It sets UTF-8 output itself, so Tamil and other scripts print correctly in the Windows console.

Where do I report a problem?

Open an issue on libishm1/open-science. For problems in the upstream app that also happen in AIPOCH's release, report them to aipoch/open-science.

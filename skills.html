Skills

A skill is a folder with a SKILL.md file: a procedure, checklists and templates an agent follows. The app loads the right one from your request.

How small local models use skills

  • Every fork skill has a Quick start section of five or six numbered steps near the top.
  • The entry file is under 150 lines. Longer material sits in references/ files that the agent loads one at a time.
  • Long references start with a Contents list with line numbers, so a model can read one section.

Skills from upstream Open-Science

The app also ships AIPOCH's own skills, unchanged: structure prediction (alphafold2, esmfold2, openfold3, boltz, chai1), protein design (proteinmpnn, ligandmpnn, solublempnn), docking (diffdock), sequence models (evo2, borzoi, fair-esm2), single-cell (scvi-tools, scgpt), literature-review, indication-dossier, figures (figure-composer, figure-style, paper-narrative), and compute setup (remote-compute-ssh, compute-env-setup).

Using a skill outside the app

  • Claude Code: copy a skill folder into .claude/skills/ in your project, or ~/.claude/skills/.
  • Codex and other agents: point the agent at the skill's SKILL.md.
  • Local models: give the model the Quick start and one reference file.
  • Command line: python -m lawb skills show <name> --section "Quick start (for small local models)".

A third-party LaTeX skill used privately was left out because its licence does not allow redistribution. The latex-document skill above is an original replacement.

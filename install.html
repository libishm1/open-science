Install

Everything works by clicking and asking. No terminal or command line is needed.

1. Install the desktop app (Windows)

  1. Open the releases page.
  2. Under Assets, download the file ending in -win-x64-setup.exe.
  3. Double-click it. Windows may show "Windows protected your PC" because this build is not code-signed. Choose More info, check that the file came from the releases page, then choose Run anyway.
  4. Follow the installer. It installs for your user account only and does not need administrator rights.
  5. Open Open-Science from the Start menu or the desktop shortcut.
Only download the installer from the releases page linked above. Compare its size with the one listed on the release before running it.
If you already have AIPOCH Open-Science installed: this fork uses the same app identity, so installing it replaces the upstream app. Your projects stay. After that, the app checks this fork's GitHub releases for updates, not AIPOCH's, so an upstream update cannot remove the fork's skills.

2. Get a local AI model (free, private, works offline)

Local models run on your own computer. Nothing you type or attach leaves it.

  1. Download and install the Ollama desktop app. Run its installer like any other program.
  2. Open the Ollama app. Choose a model in its model menu and send it a short message such as "hello". The app downloads the model the first time. Which model to pick:
    • Most people: qwen3:8b
    • Coding: qwen2.5-coder:7b
    • Older laptop with 8 GB of memory: qwen2.5-coder:1.5b
    See Local models for the measurements behind these choices.
  3. Leave Ollama running. It sits in the system tray.

The model menu in the Ollama app is described in public reviews of its desktop app. If your version has no model menu, the advanced section shows the one command that downloads a model.

3. Connect the model to Open-Science

  1. In Open-Science, open the settings and go to the model providers.
  2. Add a provider and choose the Ollama preset. Its address is http://localhost:11434. No key is needed.
  3. Select the model you downloaded.
  4. Create a project, then type what you want in plain language. Attach the files the task needs to the conversation.

LM Studio, llama.cpp and vLLM have presets too, if you already use one of them.

4. Optional: a cloud model

For harder tasks you can add a cloud model. It is optional and off until you add a key.

  1. In the app's model provider settings, choose Anthropic (Claude) or OpenAI.
  2. Paste your API key and save. The app encrypts the key with your operating system's protection.
  3. Select the cloud model for a project only when the data may leave your computer. Keep patient data and unpublished data on local models.

5. Using the skills

You do not need to choose a skill. Describe the task, and the agent loads the matching skill, for example:

  • "Count my screening results and draw the PRISMA flow" with your screening spreadsheet attached.
  • "Make a figure of PDB 1UBQ for a two-column journal."
  • "Convert this PDF to text and summarise the methods section."
  • "Write a Grasshopper component that panels this surface."

Each field guide has more examples: science and bioinformatics, medicine and clinical research, AEC, robotics.

Advanced: command line, scripting, VS Code

Only needed for automation, other AI agents, or scripting. Everything above works without it.

Download a model with one command, if the Ollama app has no model menu:

ollama pull qwen3:8b

The command-line workbench is in the workbench folder of the fork (git clone --branch workbench-1.0.2.1 https://github.com/libishm1/open-science.git, or the source ZIP on the release). From that folder:

powershell -ExecutionPolicy Bypass -File install.ps1 -Profile coding   # Windows
./install.sh --profile literature                                       # Linux and macOS

Then python -m lawb doctor, python -m lawb models recommend, and python -m lawb skills list. Cloud keys for the command line go in your operating system's credential store with python -m lawb keys set anthropic.

The VS Code extension runs the same commands from the Command Palette (search "LAWB").

macOS and Linux

No prebuilt installer is published for this fork yet. Build from source with npm ci, then npm run build:mac or npm run build:linux.

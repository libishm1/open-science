Open-Science Workbench fork

A desktop research workbench that runs AI agents on your own computer, with bundled skills for science, bioinformatics, medicine, architecture and engineering, and robotics. Local models by default, cloud models only if you add a key.

Download for Windows Installation guide

This fork keeps every feature of AIPOCH Open-Science and adds skills and local-model support. It is not affiliated with or endorsed by AIPOCH.

Three-minute start

  1. Download the Windows installer from the releases page and run it.
  2. Install Ollama and pull one model, for example ollama pull qwen2.5-coder:7b.
  3. Open the app, create a project, and describe your research goal in plain language.

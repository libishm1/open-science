Platform notes

  • Rhino and Grasshopper run on Windows and macOS only. From Linux, drive a Rhino host on another machine.
  • Python, IFC, Topologic and graph-ML steps run on every platform.
  • Check the document units before modelling: metres for site and building scale, millimetres for shop parts.

Example: a Grasshopper component with an agent

  1. Start Rhino with the MCP plugin loaded and run its start command. The rhino-mcp-setup skill lists the checks.
  2. Ask the agent to write the component. It follows rhino-gh-components: decide the data match first, keep the component synchronous unless it loads a large file, and derive tolerances from the model's size.
  3. Before you call it done, it follows rhino-gh-presentation-checks: the final form appears on the canvas without a script, the file reopens cold, and a numbered copy is saved.
  4. Check the result on the Rhino canvas yourself. A passing test does not prove the geometry is right.

Example: a building-performance paper

  1. Plan the simulation campaign and the review with aec-research-workflow.
  2. Screen and count the literature with research-synthesis and lawb review.
  3. Build the manuscript with academic-paper-composer and latex-document.

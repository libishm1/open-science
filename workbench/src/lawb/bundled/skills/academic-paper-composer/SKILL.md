# Academic Paper Composer

## Quick start (for small local models)

1. Start from an approved outline. Do not write without one.
2. Write one chapter at a time. Read only the section guide for that chapter.
3. After each chapter, run python scripts/chapter_quality_check.py on it.
4. Keep every claim tied to a source. Mark unknowns as [citation needed].
5. At the end, run python scripts/final_evaluation.py on the full draft.

# Academic Paper Strategist

## Quick start (for small local models)

1. Name the target venue and read two sample papers from it.
2. Write the research question in one sentence.
3. Search with the strategy in the search reference. Record each query.
4. Run python scripts/gap_analysis.py on your notes to list candidate gaps.
5. Draft the outline. Check it against the quality standards reference.

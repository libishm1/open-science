Install a model

Without the command line: open the Ollama desktop app, choose the model in its model menu, and send a short message. It downloads the first time. Then select it in Open-Science's provider settings (Ollama preset, http://localhost:11434).

With the command line (advanced):

python -m lawb models recommend              # the table above, with what you have installed
python -m lawb models install --task coding  # pulls the coding model and its smaller option
python -m lawb models install --task all     # every recommended model

Or pull a single model with Ollama directly: ollama pull qwen3:8b.

Bundling models into the installer

Model weights are several gigabytes each, so they are not packed into the app installer. The installer scripts and lawb models install download them on first setup instead, and they then work offline.
